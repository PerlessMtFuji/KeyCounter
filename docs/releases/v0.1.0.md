# KeyCounter v0.1.0

🇵🇱 [Wersja PL](v0.1.0.pl.md)

First and last release. Project frozen at MVP — what's in the binary is the whole thing.

## What this is

A small desktop keystroke tracker. It counts how many keys you press and turns that into a heatmap and a few charts. **It counts keys, not content** — nothing about the actual characters, sequences or text ever lands in the database. Just integers per key code.

All local. One SQLite file at `%APPDATA%\io.keycounter.app\keycounter.db`. No network, no account, no telemetry. Pull the Ethernet cable and it behaves identically.

## What's inside

- Live KPM with a pulse on every keystroke
- Keyboard heatmap (QWERTY / QWERTZ / Dvorak / Colemak)
- Top keys for today / 7 days / 30 days / all time
- Finger load under standard touch typing
- Day × hour punch card and a 365-day activity calendar
- Streaks, modifier mix, backspace ratio
- Achievements with a toast on each milestone
- System tray (show / hide / pause / quit), autostart
- Optional floating widget — full or compact pill, with snap-to-taskbar
- JSON export, full-history reset
- EN / PL, dark theme

## Install

Run the installer. The first launch will show SmartScreen because the build isn't signed — click **More info → Run anyway**. A code-signing cert costs more than I want to spend on a side project, so it's staying unsigned.

## Antivirus might yell

Counting global keystrokes needs a low-level keyboard hook — the same primitive keyloggers use. Defender / SmartScreen / other AVs sometimes flag unsigned builds because of that, even though the hook never records *which* keys were pressed.

The entire hook is ~50 lines in [`src-tauri/src/hook.rs`](https://github.com/PerlessMtFuji/KeyCounter/blob/main/src-tauri/src/hook.rs). If you have doubts, read it, build from source (`npm run tauri:build`) and compare. Full write-up in [docs/antivirus.md](../antivirus.md).
