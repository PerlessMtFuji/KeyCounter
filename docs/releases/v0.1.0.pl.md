# KeyCounter v0.1.0

🇬🇧 [English version](v0.1.0.md)

Pierwszy i ostatni release. Projekt zamknięty na MVP — to co jest w binarce, to całość.

## Co to jest

Mały tracker klawiatury na desktop. Liczy ile klawiszy wciskasz, robi z tego heatmapę i kilka wykresów. **Liczy klawisze, nie treść** — w bazie nie ląduje żaden tekst, sekwencja ani znak, tylko liczby per kod klawisza.

Wszystko lokalnie. Jeden plik SQLite w `%APPDATA%\io.keycounter.app\keycounter.db`. Zero sieci, zero kont, zero telemetrii. Możesz wyłączyć Wi-Fi i działa tak samo.

## Co jest w środku

- Live KPM z pulsem przy każdym uderzeniu
- Heatmapa klawiatury (QWERTY / QWERTZ / Dvorak / Colemak)
- Top klawisze: dziś / 7 dni / 30 dni / cały czas
- Obciążenie palców przy standardowym touch typingu
- Punch card dzień × godzina i 365-dniowy kalendarz aktywności
- Streaki, mix modyfikatorów, stosunek backspace
- Achievementy z toastem przy milestonach
- System tray (pokaż / ukryj / pauza / wyjście), autostart
- Pływający widget — pełny albo kompaktowa pigułka, opcjonalny snap do paska zadań
- Eksport do JSON, reset całej historii
- PL / EN, ciemny motyw

## Pliki

- `KeyCounter_0.1.0_x64-setup.exe` — instalator Windows 10/11 (x64)
- `SHA256SUMS.txt` — sumy kontrolne, gdybyś chciał zweryfikować plik

Weryfikacja w PowerShellu:
```powershell
Get-FileHash .\KeyCounter_0.1.0_x64-setup.exe -Algorithm SHA256
```

## Instalacja

Odpal instalator. Pierwsze uruchomienie pokaże SmartScreen, bo build jest niepodpisany — klikasz **More info → Run anyway**. Cert do code-signingu kosztuje więcej niż chcę wydać na projekt po godzinach, więc póki co tak zostaje.

## Antywirus może krzyczeć

Globalne liczenie klawiszy wymaga niskopoziomowego hooka — tej samej rzeczy, której używają keyloggery. Defender / SmartScreen / inne AV czasem flagują z tego powodu niepodpisane buildy, mimo że hook nigdy nie zapisuje *jakie* klawisze były wciskane.

Cały hook to ~50 linii w [`src-tauri/src/hook.rs`](https://github.com/PerlessMtFuji/KeyCounter/blob/main/src-tauri/src/hook.rs). Jeśli masz wątpliwości, przeczytaj, zbuduj z source'a (`npm run tauri:build`) i porównaj. Pełen rozkład w [docs/antivirus.pl.md](../antivirus.pl.md).
